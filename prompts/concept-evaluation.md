# Evaluate concepts with Codex

Use `docs/research/llm-evaluation.md`. This is internal artifact critique and scenario sensitivity, not a synthetic survey.

1. Freeze candidate/evidence versions. Gate truth, rights, release, destination, and format separately from taste.
2. Before judging, set an anchored rubric and explicit maximum passes/calls/time using available capacity. Track consumed effort. Cover clarity, situation relevance, proof/specificity, differentiation, brand/offer recognition, next action, and contextual fit. Unknown is valid; do not manufacture a total probability.
3. Use neutral labels and comparable presentation. Hide authorship when possible; disclose same-context review. Ask for quoted artifact spans and concrete defects before preference.
4. Whenever pairwise preference influences a decision, initiate both A/B and B/A; use isolated context when available. If reversal cannot be completed, label the preference provisional and the order check incomplete. Record correlated-model limits; a changed ranking becomes unstable/inconclusive, not a forced winner.
5. Inspect a few evidence-linked use/objection scenarios. Label hypothetical assumptions. Do not generate consumer vote counts, buying intent, WTP, segment shares, or confidence intervals.
6. Return revisions, tradeoffs, dissent, and a bounded internal preference or abstention. Log model/version if exposed, context/rubric/candidate versions, order, effort used, and task/domain-specific calibration status. Known-defect fixture success establishes only tested defect detection; it never calibrates audience prediction. When the effort limit is reached, preserve partial findings and unresolved checks rather than loop until endorsement.
7. Save the revised artifact and review through the normal authority path. Model endorsement never grants publication or spending.

No extra model subscription is required. Use extra critique passes only when useful and permitted. If no runtime exists, keep a clear manual evaluation record; do not claim automatic scoring/approval enforcement.
